# Trámites en línea — Puerto Escondido, Córdoba

Demo / piloto de digitalización de trámites municipales. Permite generar en PDF, directamente desde el navegador:

- Certificado de residencia
- Paz y salvo de Industria y Comercio
- Permiso de funcionamiento

## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `tramites-puerto-escondido`).
2. Sube el contenido de este `.zip` a la raíz del repositorio (debe quedar el archivo `index.html` en la raíz).
3. Ve a **Settings → Pages**.
4. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda. En un par de minutos GitHub te dará una URL como:
   `https://tu-usuario.github.io/tramites-puerto-escondido/`

No requiere backend ni build: es un único archivo HTML autocontenido.
